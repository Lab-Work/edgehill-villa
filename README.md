# Edgehill Ave & Villa Pl

LiDAR traffic report for the intersection of Edgehill Ave and Villa Pl in
Nashville, Tennessee.

The report presents traffic-volume, turning-movement, speed, and multimodal
travel data collected for the study area. The published report is contained in
[`index.html`](./index.html).
